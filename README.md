# Молочный комбинат «Полесье»

# Ссылка на репозиторий Github

https://github.com/bkmz911/demo-ekz

Учебное Electron-приложение на Node.js.

## Запуск

```bash
npm install
npm start
```

## Данные

- admin / admin123 — администратор
- user / user123 — пользователь

## Функции

Авторизация, CAPTCHA, блокировка после 3 ошибок, админка пользователей, SQL-запрос, валидация ФИО, работа с API.

## API

Electron → локальный `server.js` → TransferSimulator.
